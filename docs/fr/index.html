DiceAudio

DiceAudio vous aide à gérer l'audio de vos parties de jeu de rôle sur table. Rassemblez dans une seule bibliothèque les musiques, ambiances et effets sonores que vous utilisez, construisez des scènes en couches qui suivent ce qui se passe à la table, et pilotez toute la soirée depuis une seule fenêtre.

Télécharger Dépôt GitHub

Ce que fait l'application

DiceAudio est fait pour le maître de jeu qui veut que le son suive ce qui se passe à la table, sans avoir à se battre avec un lecteur multimédia au milieu de la partie.

La bibliothèque audio

Vos fichiers audio sont organisés en dossiers et étiquetés selon trois catégories : le type (musique, ambiance ou effet sonore), le lieu et l'expression. Une recherche parcourt toute la bibliothèque, des filtres la réduisent par type, et les fichiers eux-mêmes restent là où vous les avez mis sur votre disque.

Importer votre audio

Téléchargez depuis YouTube, SoundCloud et des milliers d'autres sites grâce au téléchargeur intégré : mettez plusieurs liens en file, choisissez le dossier de destination et lancez. Vous pouvez aussi importer les fichiers que vous avez déjà sur votre disque.

Réglages de piste

Chaque élément a son propre volume et peut être découpé sur la portion que vous voulez réellement jouer. Le découpage est non destructif, le fichier d'origine n'est jamais modifié.

Les scènes

Une scène est construite à partir de plusieurs couches, chacune étant une ambiance, une musique ou un effet sonore pris dans votre bibliothèque, avec son rôle et ses réglages de lecture.

Les contextes

Une scène peut avoir plusieurs contextes, qui sont les états dans lesquels elle peut se trouver, par exemple calme, mystérieux ou bagarre. Chaque contexte retient un niveau pour chaque couche, et y passer fait fondre toute la scène sur le temps de transition que vous avez défini.

Les scénarios

Un scénario est la liste ordonnée de ce que vous comptez jouer pendant une séance, et les scénarios sont rassemblés en groupes, en général un par aventure ou par arc narratif. Un élément peut être une piste seule, une playlist, une sélection aléatoire basée sur des critères d'étiquettes, ou une scène entière.

Les presets

N'importe quel élément de scénario peut être enregistré comme preset avec une catégorie, puis réutilisé pour démarrer une nouvelle scène ou un nouvel élément sans tout reconstruire.

Contrôle à distance

DiceAudio peut démarrer un serveur HTTP local qui expose la lecture, la navigation dans un scénario et les contextes des scènes. Une autre application peut alors piloter le son : une note Trilium avec le widget fourni, ou une automatisation DiceCombats quand quelque chose se passe dans un combat. Le serveur est désactivé par défaut et s'active dans les réglages.

Sur votre machine

La bibliothèque pointe vers les fichiers audio que vous avez déjà et les réglages restent sur votre ordinateur. L'interface est en anglais et l'application tourne sur Windows. Le mobile n'est pas disponible pour le moment, cela viendra peut-être plus tard. DiceAudio est gratuite et open source sous GPL-3.0.

Un aperçu

Ces captures sont prises dans une bibliothèque réellement utilisée, elles montrent donc à quoi ressemble une séance préparée.

L'éditeur de scène

Une scène est faite de couches et de contextes, et les deux s'éditent sur la même page. Chaque couche pointe vers un élément de votre bibliothèque et garde ses propres réglages. Chaque contexte retient quelles couches jouent et à quel volume, avec le temps que doit prendre le fondu. Passer de Calme à Mystérieux pendant la partie ne demande alors qu'un clic.

Les scénarios

Un groupe rassemble les scénarios d'une aventure, et chaque scénario liste dans l'ordre ce que vous comptez jouer. Les pistes seules ont leurs propres boutons de lecture et leur barre de progression, tandis que les scènes affichent leurs contextes sous forme de boutons, pour démarrer directement dans le bon état.

Ce que peut être un élément de scénario

Un élément n'est pas forcément une piste : ce peut être une playlist, une sélection aléatoire basée sur des critères, ou une scène entière. Des effets sonores peuvent y être attachés, et l'élément complet peut être enregistré comme preset pour plus tard.

La lecture aléatoire par critères

Au lieu de choisir une piste, vous décrivez ce que vous voulez et vous laissez DiceAudio choisir. Les critères se construisent à partir des catégories d'étiquettes, combinées avec ET ou OU, si bien qu'une ambiance de forêt à l'expression mystérieuse joue autre chose à chaque fois que le groupe entre dans les bois.

La bibliothèque

Chaque élément garde ses étiquettes, sa place dans les dossiers et ses réglages de lecture, et peut être joué, édité, déplacé ou supprimé depuis sa carte.

Dossiers et filtres

Votre bibliothèque est organisée dans des dossiers que vous créez vous-même, avec une recherche sur tous les éléments et des filtres par type. La barre du haut affiche toujours ce qui est en train de jouer.

Le téléchargeur audio

Collez un ou plusieurs liens, vérifiez ce qui est en file, choisissez le dossier de destination et lancez le téléchargement. Les pistes arrivent directement dans votre bibliothèque, prêtes à être étiquetées.

Réglages de piste et découpage

Réglez le volume d'une piste et, si vous n'en avez besoin que d'une partie, déplacez le début et la fin du découpage sur la forme d'onde. L'aperçu ne joue que la région sélectionnée et le fichier d'origine n'est jamais modifié.

Contrôle à distance et intégration Trilium Notes

DiceAudio embarque un serveur HTTP et peut être piloté par une API HTTP depuis n'importe quel service externe. L'application est aussi livrée avec un widget Trilium Notes qui permet d'intégrer le lecteur DiceAudio dans n'importe laquelle de vos notes. C'est très pratique, car vous placez le bon extrait audio directement là où il est utile dans votre scénario ou votre script.

Installer le widget Trilium

  • Créez une note de code Trilium nommée DiceAudioWidgetHTML avec le langage réglé sur HTML, et collez-y le contenu de DiceAudioWidgetHTML.html.
  • Créez une note de code enfant avec le langage réglé sur JavaScript frontend, et collez-y le contenu de DiceAudioWidgetJS.frontend.js.
  • Créez une autre note nommée DiceAudio widget render. Dans les Basic properties de la note, réglez le type sur Render Note. Puis dans les Owned Attributes de la note, ajoutez ~renderNote=DiceAudioWidgetHTML.
  • Après ces étapes, la note doit s'afficher. Quand DiceAudio est lancé, elle ne doit pas afficher ⚠ DiceAudio not reachable.
  • Vous pouvez maintenant inclure cette note n'importe où en passant par le menu Paragraphe -> Insert (+ button) -> Insert note -> sélectionnez la note DiceAudio widget render

Un écosystème

L'écosystème Dice compte aujourd'hui deux applications : DiceAudio et DiceCombats. Elles sont écrites par la même personne et peuvent se parler, donc ce qui se passe dans un combat peut piloter ce que votre table entend.

DiceAudio Cette application

La bibliothèque, les scènes et les scénarios. Son API locale permet à une autre application de lancer une scène, de la faire avancer ou de tout arrêter.

DiceCombats

DiceCombats gère les combats de votre table : des créatures construites avec les champs que votre système demande, l'initiative, les types de dégâts et les résistances, et un journal de combat. Ses automatisations peuvent appeler l'API de DiceAudio quand un coup est appliqué.

Voir la page DiceCombats

Installation

Il n'y a pas d'installateur ni de compte à créer. L'application stocke ses données sur votre machine.

  • Windows: Téléchargez le ZIP de la dernière version, extrayez-le où vous voulez et lancez DiceAudio.exe. Épinglez-le au menu démarrer si vous le voulez sous la main.
  • Android: L'application n'est pas disponible sur mobile pour le moment. Cela viendra peut-être plus tard.

Compiler depuis les sources

Il vous faut le SDK .NET 10 et les charges de travail MAUI installées. Le reste est restauré depuis NuGet.

git clone https://github.com/YannCharbon/DiceAudio.git
dotnet workload install maui-windows maui-android
dotnet publish DiceAudio/DiceAudio.csproj -f net10.0-windows10.0.19041.0 -c Release -p:RuntimeIdentifierOverride=win10-x64 -p:WindowsPackageType=None -p:IncludeAllContentForSelfExtract=true -p:PublishReadyToRun=true -p:IncludeNativeLibrariesForSelfExtract=true

À propos de l'IA

J'ai commencé à développer DiceAudio en septembre 2023, dans le cadre d'un ancien projet jamais publié, à une époque où je ne considérais pas encore les outils de code assistés par IA comme assez fiables pour ce genre de travail. Jusqu'au début 2026, j'ai écrit tout le code moi-même. Ces outils ayant beaucoup progressé, j'utilise maintenant Claude Code pour implémenter plus vite les nouvelles fonctionnalités. J'aime écrire du code, mais ce à quoi je tiens encore plus, c'est d'avoir du temps pour travailler mes scénarios de JDR. Confier une partie du développement à l'IA me laisse davantage de temps pour ce côté créatif du loisir. Si l'usage de l'IA dans le projet vous dérange, je comprends tout à fait que vous préfériez ne pas utiliser DiceAudio. Je tiens malgré tout à être clair sur un point : l'IA est ici un outil de développement. Les fonctionnalités, les choix de conception et la direction générale de DiceAudio viennent toujours de moi, un maître de jeu qui construit un outil pour d'autres maîtres de jeu.
