Vos données

Votre bibliothèque, vos scènes, vos scénarios et vos réglages restent sur votre ordinateur, dans un dossier que vous pouvez choisir. Cette page décrit comment les partager avec d'autres MJ, comment DiceAudio les sauvegarde et comment utiliser la même bibliothèque sur plusieurs ordinateurs.

L'interface de DiceAudio n'existe qu'en anglais : les noms des boutons sont donc cités tels que l'application les affiche.

Partage

Les pistes, dossiers, scènes, scénarios, groupes de scénarios, collections et presets peuvent être exportés à l'aide des boutons Export placés à côté d'eux. Dans les réglages (Settings), section Data, Export the whole library… enregistre l'ensemble en une seule fois.

Le fichier contient également tout ce qu'utilise le contenu exporté. Un groupe de scénarios est ainsi accompagné de ses scènes, des pistes qu'elles jouent, ainsi que des dossiers et des étiquettes de ces pistes. La personne qui l'importe dispose d'un groupe de scénarios prêt à être joué.

Contenu du fichier

L'export prend la forme d'un fichier .dicea. Celui-ci contient la description de votre contenu et les liens de téléchargement des pistes, mais jamais l'audio lui-même. Lorsque certaines pistes n'ont pas de lien de téléchargement et que leur fichier n'est pas inclus, la fenêtre d'export vous le signale : la personne qui importera le fichier devra leur attribuer elle-même un fichier.

Inclure les fichiers audio

Si vous cochez Also save the audio files, in a second file (.diceamedia), les fichiers audio présents sur votre ordinateur sont enregistrés dans un second fichier, à côté du premier. DiceAudio indique le nombre de fichiers concernés et la place qu'ils occupent.

La première fois que vous le faites au cours d'une session, DiceAudio vous rappelle que les fichiers audio sont souvent protégés par le droit d'auteur. Vous pouvez utiliser ce second fichier pour votre usage personnel, par exemple pour transférer votre bibliothèque sur un autre ordinateur. En revanche, il n'est pas permis de partager ces fichiers publiquement, ni avec des personnes qui n'en détiennent pas les droits.

Importer un fichier

Le bouton Import a DiceAudio file… se trouve dans l'explorateur, sur la page des scènes, sur celle des scénarios, dans l'onglet Local scenes d'un groupe de scénarios, ainsi que dans les réglages, section Data.

  1. Cliquez sur Import a DiceAudio file… et choisissez le fichier .dicea.
  2. Si l'export est accompagné d'un fichier audio (.diceamedia), DiceAudio l'utilise lorsqu'il se trouve dans le même dossier. Dans le cas contraire, il vous le demande : choisissez Open the audio files… pour l'indiquer, ou Continue without them pour vous en passer.
  3. Lorsque rien dans le fichier ne figure déjà dans votre bibliothèque, un récapitulatif présente ce qui sera ajouté. Sinon, vous décidez du sort de chaque élément, comme expliqué ci-dessous.
  4. Cliquez sur Import. DiceAudio sauvegarde d'abord vos données, puis importe le fichier et indique ce qui a été ajouté, remplacé ou laissé de côté.

Selon la page d'où vous importez

Chaque page s'attend à un certain type de contenu : des pistes et des dossiers dans l'explorateur, des scènes sur la page des scènes, des groupes de scénarios et des scénarios sur celle des scénarios. Si le fichier n'en contient aucun, DiceAudio vous en avertit en haut de la fenêtre d'importation, et vous pouvez tout de même importer le reste du fichier.

Depuis l'onglet Local scenes d'un groupe de scénarios, les scènes du fichier deviennent des scènes locales de ce groupe. Le reste du fichier est importé normalement.

Décider du sort de chaque élément

Lorsqu'une partie du fichier figure déjà dans votre bibliothèque, chaque élément est marqué New, Up to date, Differs ou Name already used. À côté, une liste propose les choix possibles pour cet élément, avec sous elle une courte explication du choix retenu. Le choix proposé est déjà sélectionné.

  • Import as a copy ajoute la version importée à côté de la vôtre, sous un nouveau nom. La vôtre reste inchangée.
  • Replace the local one remplace votre version par celle du fichier.
  • Keep the local one laisse de côté la version importée ; ce qui l'utilise dans le fichier utilisera la vôtre.
  • Merge, pour un groupe de scénarios ou un dossier, conserve le vôtre et y ajoute le contenu de la version importée.
  • Import with a new name ou Keep both with the same name, lorsque seul le nom est déjà utilisé.
  • Use the local one instead laisse de côté l'élément importé et utilise le vôtre partout où le fichier en a besoin.

Pour donner la même réponse à de nombreux éléments à la fois, utilisez le bouton situé à côté de la liste, par exemple Same choice for all 12 audio items marked “Differs”.

Les parties d'un groupe de scénarios, comme un scénario ou un élément de scénario, rejoignent le groupe ou le scénario que vous indiquez sous Add to the scenario group et Add to the scenario.

Le nom des copies

Lorsqu'au moins un élément doit recevoir un nouveau nom, une barre intitulée Names of copies apparaît en haut de la fenêtre d'importation. Elle permet de choisir un texte placé avant le nom et un texte placé après. Par défaut, la copie de « Forêt » s'appelle « Forêt (2) ». Si vous modifiez ces textes, les noms proposés sont mis à jour, sauf ceux que vous avez saisis vous-même. DiceAudio ajoute toujours un numéro lorsqu'un nom est déjà utilisé. Le bouton Import reste indisponible tant qu'un nom est vide ou déjà utilisé.

Récupérer l'audio

Après l'importation, DiceAudio cherche un fichier pour chaque nouvelle piste :

  • dans le fichier audio .diceamedia, si vous l'avez ouvert ;
  • sur votre ordinateur, parmi les fichiers qui portent le même nom ou qui ont la même taille ;
  • à défaut, en téléchargeant la piste depuis son lien, par la liste des téléchargements.

Les pistes encore dépourvues de fichier sont ensuite listées, chacune avec un bouton Pick file…. Vous pouvez aussi vous en occuper plus tard : l'explorateur les signale, comme le décrit la section suivante.

Fichiers audio manquants

Dans l'explorateur, la carte d'une piste dont le fichier ne se trouve pas sur cet ordinateur l'indique, avec un bouton pour y remédier :

  • Not downloaded yet : la piste possède un lien de téléchargement, mais n'a jamais été téléchargée. Download l'ajoute à la liste des téléchargements.
  • Not found on disk : la piste avait un fichier, qui ne se trouve plus dans le dossier Audio. Pick file… permet de choisir de nouveau ce fichier, que DiceAudio copie alors dans le dossier Audio. Si la piste possède un lien, Download est également proposé.
  • No audio file : la piste n'a ni fichier ni lien. Pick file… permet de lui en attribuer un.
  • Only in the cloud : le fichier se trouve dans votre dossier de données, mais votre service de synchronisation ne l'a pas encore téléchargé sur cet ordinateur.

Dans un dossier, Download all ajoute à la liste des téléchargements toutes les pistes de ce dossier qui n'ont pas encore été téléchargées. Le bouton indique le nombre de pistes concernées et n'apparaît que s'il y en a au moins une.

Le filtre Missing files de l'explorateur rassemble les pistes sans fichier de tous les dossiers.

Sauvegardes

DiceAudio sauvegarde vos données à la première ouverture de chaque journée, ainsi qu'avant chaque importation, chaque restauration et chaque copie de vos données vers un autre dossier. Une sauvegarde contient votre bibliothèque, vos dossiers, étiquettes, scènes, groupes de scénarios, presets et réglages, mais jamais les fichiers audio eux-mêmes.

Les dix sauvegardes automatiques les plus récentes sont conservées. Celles que vous effectuez avec Back up now ne sont jamais supprimées par l'application, pas plus que celles qui précèdent une importation, une restauration ou un changement de dossier.

Restaurer une sauvegarde

  1. Ouvrez les réglages (Settings), section Data. La sauvegarde la plus récente y est affichée.
  2. Cliquez sur Restore à côté d'elle, ou sur All backups… pour voir les autres, avec leur date, l'ordinateur concerné et leur motif.
  3. Confirmez. DiceAudio sauvegarde d'abord vos données actuelles, afin que vous puissiez revenir en arrière si nécessaire, puis restaure la sauvegarde choisie.

Une fois la sauvegarde restaurée, DiceAudio liste les pistes dont le fichier ne se trouve plus sur cet ordinateur.

Les sauvegardes sous forme de fichier

Save a backup to a file… copie une sauvegarde à l'emplacement de votre choix, et Restore from a file… permet de la récupérer. Open the backups folder affiche l'emplacement où DiceAudio les conserve.

Le dossier de données

DiceAudio conserve votre bibliothèque, ses sauvegardes et vos fichiers audio dans un même dossier de données. Les réglages (Settings), section Data, indiquent son emplacement et permettent d'en choisir un autre.

  1. Cliquez sur Choose another folder… et sélectionnez le nouveau dossier.
  2. DiceAudio indique la place occupée par vos fichiers audio et l'espace libre sur le disque de destination. Confirmez avec Move my data.
  3. DiceAudio arrête la lecture et les téléchargements, copie l'ensemble, vérifie la copie, puis redémarre avec le nouveau dossier.
  4. Vos anciennes données restent en place. Une fois que vous avez vérifié que tout se trouve dans le nouveau dossier, vous pouvez les supprimer avec Delete the old copy.

Back to the default folder ramène vos données à leur emplacement d'origine. Un dossier situé dans AppData ne peut pas être utilisé, et si le dossier choisi contient déjà d'autres fichiers, DiceAudio place ses données dans un sous-dossier.

Un dossier qui contient déjà des données de DiceAudio

Il arrive que le dossier choisi contienne déjà des données de DiceAudio, provenant par exemple d'un autre ordinateur. DiceAudio présente alors le contenu des deux côtés et propose trois possibilités :

  • Use the folder's data utilise le dossier tel quel. Vos données actuelles restent à leur emplacement.
  • Replace it with mine sauvegarde d'abord les données du dossier dans ses propres sauvegardes, puis les remplace par les vôtres.
  • Merge ajoute vos données à celles du dossier ; lorsqu'un élément existe des deux côtés, vous décidez de la suite, comme lors d'une importation.

Utiliser plusieurs ordinateurs

Un dossier de données synchronisé par OneDrive, Dropbox ou un service similaire permet d'utiliser la même bibliothèque sur plusieurs ordinateurs. Je vous conseille de régler le service pour qu'il conserve toujours les fichiers de ce dossier sur l'appareil ; à défaut, DiceAudio pourrait devoir attendre leur téléchargement.

Un ordinateur à la fois

Veuillez n'ouvrir DiceAudio que sur un seul ordinateur à la fois. Lorsque le dossier de données est déjà utilisé sur un autre ordinateur, DiceAudio vous le signale au démarrage, en indiquant le nom de cet ordinateur et l'heure à laquelle le dossier y a été ouvert.

  • Open anyway ouvre malgré tout le dossier de données sur cet ordinateur-ci. Si DiceAudio est encore ouvert sur l'autre ordinateur, veuillez d'abord l'y fermer.
  • Quit ferme DiceAudio sans rien modifier.

Modifications faites sur un autre ordinateur

Lorsqu'un autre ordinateur modifie les données pendant que DiceAudio est ouvert, un message vous en informe et propose un bouton Reload. DiceAudio ne recharge jamais rien de lui-même : vous pouvez attendre un moment calme de la séance. Le rechargement arrête les scénarios en cours de lecture.

Si vous enregistrez une modification sur des données changées entre-temps ailleurs, DiceAudio vous demande quelle version conserver : Reload reprend la version de l'autre ordinateur, tandis que Overwrite conserve la vôtre.

Si DiceAudio est fermé avant que vous ayez fait ce choix, votre version est conservée dans le dossier de données, dans un fichier dont le nom se termine par .unsaved.json, et DiceAudio vous le signale au démarrage suivant. Ce fichier ne peut pas être importé. Le message affiché au démarrage explique comment le mettre à la place du fichier de données auquel il correspond, après avoir effectué une sauvegarde.

Messages au démarrage

Au démarrage, DiceAudio vous signale les fichiers de données qui ne se trouvent que dans le cloud, ainsi que les copies qu'un service de synchronisation crée lorsque deux ordinateurs modifient le même fichier en même temps. DiceAudio utilise les fichiers d'origine ; je vous invite à les comparer avec ces copies et à supprimer celles dont vous n'avez pas besoin.

Lorsque le dossier est inaccessible

Si le dossier de données est inaccessible au démarrage, par exemple parce qu'un disque n'est pas branché, DiceAudio n'y crée pas de bibliothèque vide. Il propose plutôt les choix suivants :

  • Try again, une fois le disque ou le réseau connecté ;
  • Choose another folder…, si vos données se trouvent désormais ailleurs ;
  • Open the default folder instead, pour cette session uniquement. Un message vous rappelle alors que vos modifications sont enregistrées dans le dossier par défaut, et non dans votre dossier de données ;
  • Quit.
