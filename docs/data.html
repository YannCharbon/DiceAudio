Your data

Your library, scenes, scenarios and settings stay on your computer, in a folder you can choose. This page explains how to share them with other game masters, how DiceAudio backs them up, and how to use the same library on several computers.

Sharing

You can export audio items, folders, scenes, scenarios, scenario groups, collections and presets, using the Export buttons next to them. In Settings, under Data, Export the whole library… saves everything at once.

The file also holds everything the exported content uses. A scenario group, for example, comes with its scenes, the audio items they play, and the folders and tags of those items. The person who imports it gets a scenario group that is ready to play.

What the file holds

The export is a .dicea file. It holds the descriptions of your content and the download links of the audio items, but never the audio itself. If some audio items have no download link and their file is not included, the export window tells you so: the person who imports the file will have to pick their own file for them.

Including the audio files

If you tick Also save the audio files, in a second file (.diceamedia), the audio files that are on your computer are saved in a second file, next to the first one. DiceAudio shows how many files this concerns and how much space they take.

The first time you do this in a session, DiceAudio reminds you that audio files are often protected by copyright. You may use this second file for your own needs, for example to move your library to another computer. Sharing these files publicly, or with people who do not hold the rights to them, is not allowed.

Importing a file

Import a DiceAudio file… is available in the Explorer, on the Scenes page, on the Scenarios page, in the Local scenes tab of a scenario group, and in Settings under Data.

  1. Click Import a DiceAudio file… and choose the .dicea file.
  2. If the export came with an audio file pack (.diceamedia), DiceAudio uses it when it is in the same folder. Otherwise it asks you for it: choose Open the audio files… to look for it, or Continue without them.
  3. When nothing in the file is already in your library, a short summary shows what will be added. Otherwise, you choose what to do with each item, as explained below.
  4. Click Import. DiceAudio makes a backup of your data first, then imports the file and shows what was added, replaced or left out.

Where you open it from

Each page expects a certain kind of content: audio items and folders in the Explorer, scenes on the Scenes page, scenario groups and scenarios on the Scenarios page. If the file holds none of it, DiceAudio warns you at the top of the import window, and you can still import the rest of the file.

From the Local scenes tab of a scenario group, the scenes of the file become local scenes of that group. The rest of the file is imported as usual.

Choosing what to do with each item

When part of the file is already in your library, each item is marked New, Up to date, Differs or Name already used. Next to it, a list offers the choices that make sense for it, with a short explanation of the selected one underneath. The suggested choice is already selected.

  • Import as a copy adds the imported version next to yours, under a new name. Yours is not changed.
  • Replace the local one overwrites your version with the imported one.
  • Keep the local one leaves the imported version out. Anything imported that uses it then uses yours.
  • Merge, for a scenario group or a folder, keeps yours and adds what the imported one contains.
  • Import with a new name or Keep both with the same name, when only the name is already used.
  • Use the local one instead leaves the imported one out and uses yours wherever the file needs it.

To give the same answer to many items at once, use the button next to the list, for example Same choice for all 12 audio items marked “Differs”.

The parts of a scenario group, such as a scenario or a scenario item, go into the scenario group or the scenario you choose under Add to the scenario group and Add to the scenario.

Names of the copies

When at least one item needs a new name, a bar at the top of the import window shows Names of copies, with a text to put before the name and a text to put after it. By default, a copy of “Forest” is named “Forest (2)”. If you change these texts, the suggested names are updated, except the ones you have typed yourself. DiceAudio still adds a number when a name is already used, and Import stays unavailable while a name is empty or already used.

Getting the audio back

After the import, DiceAudio looks for a file for each new audio item:

  • in the audio file pack, if you opened one;
  • on your computer, a file with the same name or the same size;
  • otherwise, from the item's download link, through the download list.

The items still without a file are then listed, each with a Pick file… button. You can also leave them for later: the Explorer shows them again, as explained in the next section.

Missing audio files

In the Explorer, an audio item whose file is not on this computer says so on its card, with a button to fix it:

  • Not downloaded yet: the item has a download link but has never been downloaded. Download adds it to the download list.
  • Not found on disk: the item had a file, but it is no longer in the Audio folder. Pick file… lets you choose the file again, and DiceAudio copies it into the Audio folder. If the item has a download link, Download is offered too.
  • No audio file: the item has neither a file nor a link. Pick file… gives it one.
  • Only in the cloud: the file is in your data folder, but your synchronisation service has not downloaded it to this computer yet.

In a folder, Download all adds every item of that folder that is not downloaded yet to the download list. The button shows how many items this concerns, and only appears when there is at least one.

The Missing files filter of the Explorer gathers the items without a file from every folder.

Backups

DiceAudio backs up your data the first time you open it each day, and before every import, every restore and every copy of your data to another folder. A backup holds your library, folders, tags, scenes, scenario groups, presets and settings, but never the audio files themselves.

The ten most recent automatic backups are kept. The ones you make with Back up now, and those made before an import, a restore or a change of folder, are never deleted by the app.

Restoring a backup

  1. Open Settings and go to the Data section. The most recent backup is shown there.
  2. Click Restore next to it, or All backups… to see the others with their date, computer and reason.
  3. Confirm. DiceAudio first backs up your current data, so that you can go back if needed, then restores the backup you chose.

Once the backup is restored, DiceAudio lists the audio items whose file is no longer on this computer.

Backups as files

Save a backup to a file… copies a backup to the place you choose, and Restore from a file… brings one back. Open the backups folder shows where DiceAudio keeps them.

The data folder

DiceAudio keeps your library, its backups and your audio files together in one data folder. In Settings, under Data, you can see where it is and choose another one.

  1. Click Choose another folder… and select the new folder.
  2. DiceAudio shows how much space your audio files take and how much is free on the target drive. Confirm with Move my data.
  3. DiceAudio stops playback and downloads, copies everything, checks the copy and restarts with the new folder.
  4. Your previous data stays where it was. Once you have checked that everything is in the new folder, you can remove it with Delete the old copy.

Back to the default folder moves your data back to where it was at first. A folder inside AppData cannot be used, and if the folder you choose already holds other files, DiceAudio keeps its data in a subfolder.

A folder that already holds DiceAudio data

The folder you choose may already hold DiceAudio data, for example from another computer. DiceAudio then shows what each side contains and offers three choices:

  • Use the folder's data switches to the folder as it is. Your current data stays where it is.
  • Replace it with mine backs up the folder's data in its own backups, then replaces it with yours.
  • Merge adds your data to the folder's, and you choose what to do when an item exists on both sides, as with an import.

Using several computers

A data folder that OneDrive, Dropbox or a similar service keeps in sync lets you use the same library on several computers. Please set the service to always keep the files of this folder on the device, otherwise DiceAudio may have to wait for them to download.

One computer at a time

Please open DiceAudio on one computer at a time. When the data folder is already in use on another computer, DiceAudio says so at start, with the name of that computer and the time it was opened there.

  • Open anyway opens the data folder here as well. If DiceAudio is still open on the other computer, please close it there first.
  • Quit closes DiceAudio without changing anything.

Changes made on another computer

When another computer changes the data while DiceAudio is open, a message tells you so, with a Reload button. DiceAudio never reloads by itself, so you can wait for a quiet moment in the session. Reloading stops the scenarios that are playing.

If you save a change to data that was changed elsewhere in the meantime, DiceAudio asks which version to keep: Reload takes the other computer's version, and Overwrite keeps yours.

If DiceAudio is closed before you have made that choice, your version is kept in the data folder, in a file whose name ends in .unsaved.json, and DiceAudio tells you about it at the next start. This file cannot be imported. The message at start explains how to put it in place of the data file it belongs to, after making a backup.

Notices at start

When it starts, DiceAudio tells you about data files that are only in the cloud, and about the copies a synchronisation service makes when two computers change the same file at once. DiceAudio uses the original files; please compare them with the copies and delete the copies you do not need.

When the folder cannot be reached

If the data folder cannot be reached when DiceAudio starts, for example because a drive is not connected, DiceAudio does not create an empty library there. It offers these choices instead:

  • Try again, once the drive or the network is connected;
  • Choose another folder…, if your data is now somewhere else;
  • Open the default folder instead, for this session only. A message then reminds you that your changes are saved in the default folder, not in your data folder;
  • Quit.
